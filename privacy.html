プライバシーポリシー

見える授業（Instagram @mieru.jugyo）と、その投稿に使うツール「reel-loop」について　／　2026年11月9日

1. このツールがすること

reel-loop は、見える授業の運営者が自分で作った短い動画を、運営者自身の Instagram・YouTube・TikTok のアカウントに投稿し、その投稿の再生数などの数字を読むためだけに使う、運営者専用のツールです。運営者以外の人が使うことはありません。

2. 扱う情報

  • 運営者自身のアカウントへの投稿の許可（アクセストークン）。暗号化して保管し、表示・共有しません
  • 運営者自身の投稿の数字（再生数・いいね数・保存数など）と、フォロワーの年代・地域などの集計値（個人を特定しない数）

見てくださる方の名前・メールアドレス・コメント・メッセージなど、個人の情報は集めません。

3. Google のユーザーデータ（YouTube）

YouTube Data API で使うのは、運営者のチャンネルへの動画のアップロードと、そのチャンネルの動画の数字の読み取りだけです。取得したデータを第三者に渡したり、広告に使ったり、販売したりしません。reel-loop による Google ユーザーデータの利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

許可は、Google アカウントの「サードパーティによるアクセス」からいつでも取り消せます。

4. 保管と削除

投稿の記録と数字は、運営者の非公開の保管場所に置きます。不要になった許可は取り消し、記録は運営者の判断で削除します。
